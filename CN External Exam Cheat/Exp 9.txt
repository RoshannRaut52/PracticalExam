Experiment 9: Selective Repeat – Viva Questions and Answers
Basic Questions
1. What is Selective Repeat?
Selective Repeat is a sliding window protocol used for reliable data transmission.

2. What is the purpose of Selective Repeat?
To transmit data efficiently and retransmit only lost or damaged frames.

3. Which layer uses Selective Repeat?
Data Link Layer.

4. What is a sliding window protocol?
It allows multiple frames to be transmitted before receiving acknowledgments.

5. What is a frame?
A frame is a unit of data transmitted at the Data Link Layer.

6. What is ACK?
ACK stands for Acknowledgment. It confirms successful receipt of a frame.

7. What is ARQ?
ARQ stands for Automatic Repeat reQuest. It is used for error control through retransmission.

8. What happens when a frame is lost?
Only the lost frame is retransmitted.

9. Why is it called Selective Repeat?
Because the sender selectively retransmits only the frames that are lost or damaged.

10. What is the main advantage of Selective Repeat?
It avoids unnecessary retransmission of correctly received frames.

Technical Questions
11. What is window size?
It is the maximum number of frames that can be sent without waiting for acknowledgments.

12. What is a sender window?
It represents the frames that the sender is currently allowed to transmit.

13. What is a receiver window?
It represents the frames that the receiver can accept and buffer.

14. Does Selective Repeat use a timer?
Yes, it uses individual timers for outstanding frames.

15. Can Selective Repeat accept out-of-order frames?
Yes, it can accept and temporarily store out-of-order frames.

16. What is buffering?
Buffering means temporarily storing received data before processing or delivering it.

17. What happens if an acknowledgment is lost?
The sender may retransmit the frame after a timeout.

18. What is the maximum window size for an N-bit sequence number? 
2^{N-1}

19. What is the difference between Go-Back-N and Selective Repeat?

20. What is the difference between Stop-and-Wait and Selective Repeat?
Stop-and-Wait sends one frame at a time, whereas Selective Repeat allows multiple frames to be sent.

Important Practical Questions
31. What is the disadvantage of Selective Repeat?
It requires more memory and is more complex to implement.

32. Why is Selective Repeat more efficient than Go-Back-N?
Because it retransmits only lost or damaged frames.

33. What is timeout?
Timeout occurs when an acknowledgment is not received within the specified time.

34. What is retransmission?
Sending a frame again when it is lost or damaged.

35. Why does Selective Repeat require buffering?
To store correctly received frames that arrive out of order.
