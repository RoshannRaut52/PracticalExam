Experiment 5: Character Stuffing – Viva Questions and Answers
Basic Questions
Q1. What is framing?
Framing is the process of dividing a continuous stream of data into smaller units called frames.

Q2. What is character stuffing?
Character stuffing is a framing technique in which an extra escape character is inserted before special characters in the data.

Q3. Why is character stuffing used?
To distinguish data characters from special frame delimiter characters.

Q4. Which layer of the OSI model performs framing?
Data Link Layer (Layer 2).

Q5. What is a flag character?
A special character used to indicate the beginning or end of a frame.

Q6. What is an escape character?
A special character inserted before a flag or escape character appearing in the data.

Q7. What is destuffing?
The process of removing the extra escape characters at the receiver to recover the original data.

Conceptual Questions
Q8. What is the difference between bit stuffing and character stuffing?
Bit Stuffing	                                Character Stuffing
Works with bits.	                             Works with characters or bytes.
Inserts an extra bit.	                         Inserts an escape character.
Inserts 0 after five consecutive 1s in HDLC.	 Inserts ESC before special characters.


Q9. What happens if the data contains a flag character?
An escape character is inserted before the flag character.

Q10. What happens if the data contains an escape character?
Another escape character is inserted before it.

Q11. What is the purpose of a frame?
A frame carries data in a structured format for transmission over a network.

Q12. What is the full form of ESC?
Escape Character.

Q13. What is the full form of FLAG?
FLAG is a frame delimiter; it is not an abbreviation.
